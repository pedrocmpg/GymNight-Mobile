**GymNight Mobile** is a streamlined, distraction-free companion application built with **React Native** and **JavaScript**. It is engineered to act as a fast, high-performance interface for logging workout intensities and tracking progressive overload directly from the gym floor.

> 🖥️ **Looking for the desktop analytics dashboard?** Check out the [GymNight-Desktop](REPOSITORY_LINK_HERE) repository to view deep historical data analysis and advanced metrics.

---

## ⚡ Mobile Philosophy: Pure Focus
GymNight Mobile eliminates the clutter. No social feeds, no gamification badges, and no distracting configurations. It is a minimalist logging tool designed to let you enter your numbers in under 3 seconds between sets and put your phone back down.

## ✨ Key Features

* **On-the-Fly Workout Logging:** High-speed interface to log sets, reps, and weights with single-tap controls.
* **Rest Timer Automation:** Integrated minimalist timer that triggers automatically between sets to optimize recovery windows.
* **Seamless Multi-Platform Concept:** Built as the portable client for the GymNight software ecosystem.
* **Offline-First Architecture:** Full tracking capabilities without requiring an active internet connection, ensuring reliability inside heavy gym concrete structures.
* **Clean Dark Theme:** High-contrast, low-brightness modern dark layout optimized for low-light gym environments.

---

## 🛠️ Technology Stack

* **Framework:** React Native
* **Language:** JavaScript (ES6+)
* **State Management:** Optimized local state control for zero latency during active workouts.

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js and the React Native environment properly configured on your machine.

### Installation
```bash
# 1. Clone the repository
git clone [https://github.com/pedrocmpg/GymNight-Mobile.git](https://github.com/pedrocmpg/GymNight-Mobile.git)

# 2. Navigate into the project folder
cd GymNight-Mobile

# 3. Install dependencies
npm install

# 4. Run the application
npx react-native start
